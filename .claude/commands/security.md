# /security

راجع هذا الكود كمهندس أمان.

ركز على:
- auth و authorization
- validation و sanitization
- injection risks
- XSS / CSRF / SSRF / SQLi / command injection
- secrets and environment variables
- insecure defaults
- access control
- deserialization and file upload risks
- dependency vulnerabilities

التنسيق:
- اذكر المستوى: High / Medium / Low
- اذكر الملف
- اذكر المشكلة
- اشرح أثرها
- اقترح الحل العملي
- اذكر أي اختبارات أو تدابير احتياطية

احرص على:
- عدم المبالغة في التهويل
- التركيز على المخاطر الواقعية
- اقتراح الحلول السريعة والمعقولة
- تجنب الإفصاح عن بيانات حساسة
