# /review

راجع هذا الكود كمهندس Senior Review.

راجع:
1. المنطق والأخطاء
2. الأمان
3. الأداء
4. الصيانة وسهولة القراءة
5. edge cases
6. التوافق مع معايير المشروع
7. اختبارات مفقودة أو غير كافية

التنسيق:
- ابدأ بموجز سريع
- ثم اذكر:
  - القضايا المهمة
  - مستوى الخطورة
  - الموقع/الملف
  - لماذا مهم
  - اقتراح إصلاح عملي

الأولويات:
- bugs حقيقية
- security issues
- regressions
- performance bottlenecks
- poor maintainability

تجنب:
- التعليق على الأسلوب فقط دون سبب
- التقييم اللفظي بلا دليل
- اقتراح refactor واسع بدون داعي
